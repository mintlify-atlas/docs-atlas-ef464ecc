KWCode is a local coding agent that works with small open-source models (Qwen3, DeepSeek, GLM) rather than requiring cloud-based LLMs. Instead of relying on a strong model's reasoning ability, KWCode uses a deterministic expert pipeline where each step has a fixed input/output format — so an 8B model only ever needs to do one clearly scoped task at a time.

## Why KWCode?

Existing coding agents (Claude Code, Cursor) are designed for powerful cloud LLMs. Local models struggle because they have small context windows, make repeated mistakes, and can't reliably call tools. KWCode solves these problems with a different architecture:

<CardGroup cols={2}>
  <Card title="Deterministic pipeline" icon="shield-check">
    LLM only generates code — all decisions, validation, and retry logic are handled by deterministic code. No ReAct loops that go off the rails.
  </Card>
  <Card title="BM25 + AST location" icon="magnifying-glass">
    Two-stage code location finds the right files and functions without asking the LLM to guess. 99.4% accuracy on hidden-dependency tasks.
  </Card>
  <Card title="Runtime debugging" icon="bug">
    Debug Subagent uses `sys.settrace` to capture real variable values at runtime and injects actual data into the next retry instead of guessing.
  </Card>
  <Card title="Self-improving flywheel" icon="arrows-rotate">
    Every task is recorded. Successful patterns are promoted to domain experts after passing three quality gates: pattern detection, backtest, and AB test.
  </Card>
  <Card title="Fully offline" icon="lock">
    Your code never leaves your machine. Models run locally, search runs on self-hosted SearXNG, and statistics are stored in local SQLite.
  </Card>
  <Card title="Multi-task DAG" icon="sitemap">
    Run parallel and serial task chains with `/multi`. Dependency context flows automatically from upstream to downstream tasks.
  </Card>
</CardGroup>

## Get started

<Steps>
  <Step title="Install KWCode">
    ```bash
    pip install kwcode
    ```
  </Step>
  <Step title="Launch the interactive REPL">
    ```bash
    kwcode
    ```
    On first launch, KWCode guides you through connecting to a model (local Ollama, DeepSeek, or any OpenAI-compatible API).
  </Step>
  <Step title="Point it at your project">
    ```
    > /cd /path/to/your/project
    > /init
    ```
    `/init` creates a `KWCODE.md` file where you define project-specific rules.
  </Step>
  <Step title="Run your first task">
    ```
    > fix the login validation bug in auth.py
    ```
    KWCode classifies the task, locates relevant code, generates a patch, verifies it with pytest, and reports back.
  </Step>
</Steps>

## Supported models

KWCode works with any OpenAI-compatible API. Recommended local models:

| VRAM | Recommended model |
|------|-------------------|
| 4 GB | gemma3:4b |
| 8 GB | qwen3:8b |
| 16 GB | qwen3:14b |
| 24 GB+ | qwen3:30b-a3b |

Cloud APIs (DeepSeek, Qwen, Silicon Flow, Groq, and others) work without any local GPU.
